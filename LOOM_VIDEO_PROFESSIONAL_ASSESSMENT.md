# Loom Video Professional Assessment

## Two-minute video script

Hi, I’m Mosiah. I worked on Relay AI, an app that helps support workers see exactly what a customer is looking for, how urgent it is, and who should handle it.

I found two main problems. First, the connection to the AI service was using a model name that no longer worked, so message analysis could fail. Second, the team needed a clearer way to spot urgent messages and know when the tool was unsure. When those things are unclear, a serious customer problem could wait too long or land with the wrong person.

I updated the AI connection and added clearer urgency and confidence information, along with a way to send uncertain cases for a person to review. In everyday terms, the tool can help sort the mail, put the urgent letters near the top, and flag the ones that need a closer look.

That can save support staff time and help them respond sooner to customers with serious problems. It also gives the team a more consistent starting point as the number of messages grows. The tool helps people make decisions; staff still need to use their judgment, especially when a message is unclear.

One limitation is that an AI tool can misunderstand a message, particularly when it leaves out details or describes several problems at once. A confidence signal can help point out uncertainty, but it doesn’t guarantee the answer is right.

Next, I would try the tool on a wider range of real customer messages, check how often it sorts them correctly, and ask support staff where it saves time or gets in their way. Then I’d use what we learn to improve the sorting rules and the handoff to a person.

Thanks for listening.

## Recording reminders

- Aim for a calm, conversational pace; practice once and adjust to fit two minutes.
- Keep the language natural and explain the work as you would to someone outside technology.
- Set the Loom recording so anyone with the link can view it before submitting.
